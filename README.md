# 미로찾기

AIEDU 허브(`arenarun23/aiedu`)의 하위 서비스. 손가락으로 길을 그려 짝꿍(🐭→🧀 등 8가지)에게 가는 미로 게임.

- 난이도 3단계(모두 방해꾼이 있다, 어려울수록 많고 길을 잘 막는다): **쉬워요**(칸 큼, 돌아갈 길 있음, 방해꾼 2~3마리 🐛 느리게 돌아다님) / **어려워요**(칸 작음, 방해꾼 5~6마리: 길목을 지키는 🕷️ 3마리 + 🐛 떠돌이) / **매우 어려워요**(칸 더 작음, 방해꾼 7~8마리: 🕷️ 5 + 쫓아오는 🦂 2 + 🐛, 빠름, 음악 1.1배). 별 보너스 +0/+1/+2.
- 방해꾼 종류: 🐛 떠돌이(길을 아무 데나), 🕷️ 지킴이(갈림길에서 옆길을 드나들며 길을 막는다 — 옆길로 들어간 틈에 지나간다), 🦂 추적자(가까우면 쫓아온다). 길(열린 벽)로만 다니고, 도착 칸과 출발 칸 둘레 2칸에는 못 들어온다. **닿으면 처음부터 다시**(걸음 0, 방해꾼도 제자리). 부딪힌 직후 1.5초 무적·0.7초 입력 잠금. 부딪힘 3번 이상이면 별 −1.
- 화면: 가로 화면은 왼쪽에 메뉴(단계·힌트·음악·새로 하기·안내) + 오른쪽에 미로를 최대한 크게, 세로 화면은 위쪽 메뉴 + 아래 미로.
- 맵은 판마다 달라진다: 테두리 7가지(사각형·원·삼각형·마름모·오각형·육각형·하트) × 만드는 방식 3가지(구불구불·갈래갈래·방방이, 방방이는 사각형만) × 짝꿍 8가지(벽·바닥 색도 다름). 출발·도착은 길로 가장 먼 두 칸. 별은 걸음 수로 1~3개(힌트를 쓰면 1개 줄어듦). 별 기록은 이 기기의 localStorage(`miro:` 접두어).
- 조작: 손가락·마우스로 길을 따라 끌기, 옆 칸 누르기, 방향키/WASD.
- 구조: `index.html`, `css/style.css`, `js/core.js`(공통 도우미, 레이싱 등이 있는 `arenarun23/game` 과 같은 뼈대), `js/games/maze.js`(미로 만들기·그리기·조작), `js/main.js`.
- 음악: `js/music.js` 가 웹오디오로 직접 연주(칩튠: 사각파 멜로디·베이스·드럼, 파일·저작물 없음). 쉬움 4곡(장조, 100~112bpm) · 어려움 4곡(단조, 140~154bpm), 곡마다 16마디(A A B A')이고 끝나면 다음 곡으로 끊김 없이 이어지며 마지막 곡 다음엔 처음으로 돌아간다. 게임을 시작할 때마다 다음 곡부터 나온다. 멜로디는 새로 작곡한 것이다.
- 정적 파일·상대경로만, 외부 호스트·키 없음. 이미지는 이모지, 소리는 WebAudio.

## 배포
- `main` 에 push → `.github/workflows/notify-hub.yml` 이 허브(Vercel) 재배포를 요청 → 20~60초 안에 `https://aiedu-pearl.vercel.app/miro/` 갱신. 저장소 Secret `HUB_DEPLOY_HOOK`(허브 Deploy Hook 주소) 필요. 없으면 허브가 5분마다 확인하는 안전망으로 갱신된다.
